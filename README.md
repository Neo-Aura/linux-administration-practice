# Linux Administration Practice

## About This Repository

This repository documents my hands-on Linux learning journey as I develop practical skills for Network Engineering, Cloud Computing, and DevOps.

It contains Linux commands, administration exercises, notes, and practical examples that I complete and test during my learning process.

## Topics Covered

- Linux command-line fundamentals
- File and directory management
- File permissions and ownership
- Users and groups
- Process and service management
- Package management
- Disk usage and storage basics
- Bash scripting fundamentals
